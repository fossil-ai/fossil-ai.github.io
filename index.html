Faisal Mohammad

Senior Machine Learning Engineer, Johns Hopkins University Applied Physics Laboratory

EmailLinkedInGitHub

I've spent the last decade building machine learning systems for perception that have to work outside the lab, most recently for autonomous maritime platforms at Johns Hopkins APL, where clean data is a luxury and the ocean rarely cooperates.

My research asks what a model actually relies on, and whether that still holds once the data shifts. Recent work measures how much vision–language models trust misleading cues and uses that to choose the right model for a new domain before running it there, isolates which parts of a vessel a classifier really depends on, and retrieves physically plausible vessels for scene-aware augmentation when maritime data is scarce.
